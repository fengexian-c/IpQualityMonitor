# 2.8.1 修复与验证记录

日期：2026-09-16。Windows x64 / .NET 10 NativeAOT / WinUI 自包含。测试仅使用隔离目录、本机回环和合成路由，未使用真实数据或定位令牌。

## 实施范围

- R1：同次原始观测支撑分支，撤回后续不再充分的成员贡献；时间推定不能成为分支约束或参考来源。
- R2–R5：固定阅读与统计协议、注释及原始详情独立；切换配置立即清空旧内容，异步结果校验目标/版本/记录；收起面板不因注释刷新展开。
- R6：只有区分跳纯超时可使用时间规则，错误/未探测不强行归列。等距优先过去，多个同时间依据按稳定 ID 选择。
- R7：独立分析库保留首次判断的实际计算时间、状态、语义模式和证据；重启补算单独标记，旧数据不伪造当时判断。
- R8/R9：事务快照与来源变更戳；规范化缓存只解析新增/变化的原始 JSON；相同签名复用目录，结构变动从缓存重建；未变化的后台目标跳过重建，分析异常与采样写队列隔离。
- 参考来源可跨当前筛选范围打开；多 IP 独立注释；可选逐次发送时间/状态/初测与补测明细；更新至最新解除旧代表快照的固定选择。
- 路径和原始记录下拉框复用有限选项，隐藏详情不填充列表；选中项文字变化时刷新 WinUI 显示缓存，避免切换配置后出现空白标题；相同矩阵文字不重复写入控件。

## 核心与原生回归

完整核心检查 **344 项通过**（路由历史相关 69 项），原生界面 **133 项通过**。覆盖采样、补测预算、暂停/恢复、多目标、共享写队列、导出、定位缓存/手动校准/加密令牌、统一设置、托盘、绘图，以及新分支/错误/多回应/保留期/恢复/异步状态反例。

## 归类性能

最终全量测试实测：

| 六跳独特路径记录 | 耗时 | 累计分配 |
| ---: | ---: | ---: |
| 400 | 14 ms | 12.72 MiB |
| 1200 | 62 ms | 38.49 MiB |
| 2400 | 142 ms | 76.05 MiB |

同机上一版审核中 2400 条记录约 2016 ms / 8346 MiB 累计分配。这里的累计分配不是进程常驻内存，也不单独证明或排除泄漏。新实现达到本轮 128 MiB 分配目标；性能受数据缺失程度与拓扑分歧影响。

## 连续原生压力测试

PASS 300.1 seconds; 1372 synthetic routes; 3 targets; 34 retention cycles; following/frozen/overview/comparison, range/protocol switches and tray; no forced GC.

使用三个目标，在跟随最新、固定阅读、全部目标和对比页面之间切换，切换 24 小时/7 天与 ICMP/TCP，打开/关闭原始详情、隐藏/恢复托盘，并模拟保留期轮转。没有强制 GC。

- 实际持续 300.0 秒；生成 1372 条合成路由；结束时原始库保留 191 条。
- 预热 120 秒以后，Private Bytes 为 **167.27–186.91 MiB**；首个预热后采样 167.27 MiB，结束 183.50 MiB。
- 结束工作集 196.60 MiB、托管堆 12.61 MiB、句柄 1117。
- 矩阵行与时间轴控件数有界；完整趋势与累计分配、GC 次数见 `route-memory.csv`。

控件复用修复前，同一五分钟压力脚本结束时专用内存为 230.29 MiB；对应中间构建的记录另存于 `route-memory-before-control-reuse.csv`，供对照而非最终包的验收数据。进程启动、字体/绘图缓存和 GC 节奏会带来波动，不能用两个终点断言所有内存问题已消除。

这是五分钟的加速合成负载验证，不代表已验证数天/数周真实网络运行；保留期索引大小仍随数据量增长，自定义日期范围暂未加入。
