# 节点注释使用指南（2.7.0）

## NextTrace 定位

点击右上角“统一设置”，再打开“定位数据源 / NextTrace 令牌”，将首选数据源设为 NextTrace。无 v4 令牌也可以通过内置组件自动完成 v3 PoW 认证，不需要安装或手动运行完整 NextTrace。

要优先使用 v4：

1. 点击“领取 / 刷新 v4 七天令牌”，打开 [官方领取页面](https://api.nxtrace.org/v4/api-tokens)。
2. 在网页手动完成领取，复制令牌。
3. 回到软件，将新令牌粘贴到“NextTrace v4 七天令牌”，点击保存。

软件不能替代网页的人机验证。首次保存的有效期尚不确定，下次查询从服务端读取实际到期时间；七天是从领取时间开始，粘贴旧令牌不会重置其寿命。配置为空、已知过期或被拒绝时，回退 v3 PoW。更换令牌后使用新令牌的独立状态。

留空表示沿用已保存的令牌，勾选“移除”表示删除它。IPinfo 与 NextTrace 的令牌分别加密保存，错误与日志不包含明文令牌。

## 数据库缓存与刷新

- 默认缓存 24 小时，设置中可调整刷新间隔。
- 路由发现新公网 IP，立即加入共享注释队列；私网不查询。
- 旧 IP 只有在最近 24 小时出现在路由中，且成功缓存超过刷新间隔时才自动更新。后台每 30 秒检查，受队列、网络超时和限流约束，不集中到午夜发送。
- 最近 24 小时未出现的 IP 保留缓存，不自动请求；之后再次出现且缓存过期时再更新。手动查看历史路由并点击补全属于显式按需查询。
- 多个目标共享相同 IP 的结果；v4 / v3 共用 NextTrace 缓存。重启软件或更新令牌不会让有效结果重复查询。
- 关闭“自动注释新路由”后不执行定时刷新；关闭“在线节点注释”后停止在线查询。监控与历史查看继续可用。
- 失败不会覆盖上次成功位置。短时网络异常退避，服务限流遵循冷却时间；保存新令牌后仍需遵守正在生效的服务冷却期。

## 地区与线路

NextTrace 提供城市 / 省区定位与 ASN 等字段。缺城市时使用省区，不根据延迟跳变编造地点；缺 ASN 时保留未知。电信 163、CN2 等仍结合现有 ASN / 地址段规则识别，不能认证 GIA/GT。其他来源和查询时间保留在节点依据中。

概览点击地区，或点击“校准节点”，可填写单 IP 的国家、省州、城市、依据及复核期限。校准不扩展到网段、不覆盖 ASN 或 RTT；可撤销，到期恢复数据源结果。已经保存的历史校准与最早路由注释继续保留。

本版本已移除 NextTrace 文件导入、导入记录及命令复制入口。
