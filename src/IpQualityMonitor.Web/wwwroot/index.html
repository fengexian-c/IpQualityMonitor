NextTrace 定位注释（默认离线）

启用 v3 或 v4 后，将逐个发送已观测的公网节点 IP 给 NextTrace；该服务也会看到服务器出口 IP。不上传目标名称、整条路由或历史。GeoIP 不代表真实物理位置。v3 使用 PoW，可能增加 CPU 消耗；v4 仅使用部署时挂载的密钥文件，失败不会回退 v3。服务条款和额度适用。

v4 文件更新后重新保存设置以读取新密钥。关闭不会撤回已经发出的请求。应用自限 900 次／滚动 24 小时及至少 300 毫秒间隔，不是服务保证的额度。
